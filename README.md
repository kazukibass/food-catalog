# 食品図鑑 / Food Catalog

2,538食品・18食品群を検索できる独立した食品図鑑です。

公開先: https://kazukibass.github.io/food-catalog/

## 機能

- 食品名の検索、食品群の絞り込み、30件ずつの表示
- 100gあたりのカロリー・たんぱく質・脂質・炭水化物・糖質計算値・食物繊維
- 食べた量による換算、ほかの記録アプリへ渡すJSONのコピー
- 個人の食事・運動履歴は収録せず、この図鑑では履歴を保存しません
- 共通ナビは既存の公開shell資産を参照し、`?from=portfolio` の場合に有効

## データ

`data/foods.json` は栄養量が可食部100gあたりの配列です。`id` は元食品マスターの安定したIDです。数値の単位・来歴は `data/sources.json` を参照してください。未収載は `null` で、0とは区別します。

Fridge Questの食品マスターから食品列のみ移植。食物繊維は元プロジェクトの食品表と食品名で照合し、2,390食品に収載。糖質は `max(0, 炭水化物−食物繊維)` の計算値であり、糖類・利用可能炭水化物と同じ意味ではありません。括弧付き数値は数値へ変換し、Trは0として取り込んでいます。一般食品のデータで、外食チェーンのメニューはまだ含みません。

外部アプリからは公開JSONを読み取れます。食品マスターの更新で過去の食事記録が変わらないよう、記録側は食品IDだけでなく食品名・基準量・栄養値・データ版も保存してください。食事の個人情報を公開リポジトリへ追加しないでください。

食品成分値は目安です。資料の元データや実際の食品・調理状態と異なる場合があります。元資料の権利は各権利者に帰属します。リポジトリ全体に一律の再配布ライセンスは付与していません。

## 配信

ビルド不要。GitHub Pagesでmainブランチのルートを配信します。通常のHTTPサーバーでも動作します。画面表示用データはHTMLに埋め込み、他アプリ用のJSONと一致させています。データを更新する際は両方を更新してください。
